# Scanner-Pro-v1
A Python-based network scanner that demonstrates port scanning, multithreading, and basic reconnaissance techniques used in cyberse



 Features
 •  Fast Port Scanning
 •  Multi-threading for speed
 •  Banner Grabbing (service detection)
 •  Custom Port Range
 •  Clean CLI Output

⸻

Technologies Used
 • Python 3
 • socket
 • threading
 • argparse

⸻

Installation
git clone https://github.com/Black-X-Hammer/Scanner-Pro-v1.git

python3 scanner.py -t 127-x-x-x
